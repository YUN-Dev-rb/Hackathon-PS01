# Hackathon-PS01
The Player have to Escape from a Glitched world.
Where a Glitch World Enemy is trying to hurt the player until the player escapes the GlitchVerse.

There are 3 Ability And 1 Special Ability.
1 - Change the Dimension -- used to clear the obstacles by pressing ( Q ) key
2 - Time Freeze -- used to stop the moving obstacles and clear the path in the given time by pressing ( E ) key
3 - Pulse/ Move the Parts -- used to move the parts and reach the required destination by pressing ( R ) key
4 - Boost Bar (special ability  only available in boss level) -- boost the speed by pressing ( F ) key

LEVELS 
- There are 4 levels
- level 1 is tutorial where new player can learn game mechanics
- level 2 and level 3 are little harder but follows the same pattern
- Level 4 is a boss level where the boss try to kill the player while flying in the Glitched UFO, while player have 3 lifes and a boost bar which will help the player to collect the shards and escape the GlitchedWorld.
